# iQamata LiKhaya NPO Website - Project Submission

## Project Overview
This repository contains the source code for the official website of **iQamata LiKhaya Non-Profit Organisation**, developed as part of the Web Development coursework and Portfolio of Evidence (PoE). iQamata LiKhaya is a community-based NPO dedicated to youth empowerment, social upliftment, educational workshops, and community outreach programs (such as shoe drives and children's fun days) in South Africa.

## Project Structure & File Organization
The website is built using standard **HTML5** and **CSS3**, structured cleanly across multiple pages to ensure seamless navigation and user experience:

* `index.html` — Homepage featuring a full-width immersive hero banner with a community collage background, quick preview cards with interactive hover effects, and mission spotlights.
* `about.html` — Detailed information regarding the organization's history, mission, vision, and core values.
* `services.html` — Overview of community programs, youth workshops, and support initiatives offered by the NPO.
* `enquiry.html` — Interactive inquiry form for prospective volunteers and community members to get involved.
* `contact.html` — Official contact details, location info, and direct communication channels.
* `css/style.css` — Custom stylesheet containing global styles, layout rules, grid configurations, and interactive card animations.
* `images/` — Asset directory containing organization logos, event photos, and the primary hero collage banner (`home-cover.jpeg`).

## Technical Features & Implementation
* **Responsive Layout:** Designed with modern CSS Grid and Flexbox to ensure optimal viewing across desktops, tablets, and mobile devices.
* **Immersive Visuals:** Features a high-impact full-width hero header utilizing a custom community photo collage with an overlay for text readability.
* **Interactive Elements:** Includes custom CSS transition effects (such as "bounce" hover cards) to enhance user engagement.
* **Version Control:** Managed locally and synchronized via GitHub / GitHub Desktop for robust tracking and deployment.

## Running the Website Locally
1. Clone or download the repository to your local machine.
2. Ensure all assets are properly placed inside the `images/` folder (with `logo.png` and `home-cover.jpeg` present).
3. Open `index.html` in any modern web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge), or open the folder in **Visual Studio Code** and use the **Live Server** extension to preview.
